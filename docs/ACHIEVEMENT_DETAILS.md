# توضیح مدال‌ها و مجموعه سکه‌ها

همهٔ مدال‌های تالار با کلیک روی کارت، یک دیالوگ مشترک شامل تصویر، عنوان و توضیح اسکرول‌پذیر باز می‌کنند. فیلد اختیاری description از API تالار خوانده می‌شود. پاسخ یا کش قدیمی بدون این فیلد، توضیح عمومی با عنوان مدال نشان می‌دهد. ارتباط شبکهٔ جدیدی در کلیک لازم نیست.

مدال future_investor به صورت WebP شفاف ۳۸۴×۳۸۴ در drawable-nodpi/achievement_future_investor.webp باندل شده؛ هش آن با کاتالوگ سرور یکسان است و تصویر جایگزین سرور همچنان از کش هش‌دار فعلی استفاده می‌کند. طرح با ابزار داخلی تولید تصویر، هماهنگ با جام‌های آبی و طلایی، کتاب و جوانهٔ آینده ساخته شد.

طبق تعریف جدید، مجموعه سکه‌ها برابر مجموع سکه‌های خرج‌شده و موجودی خرج‌نشده است. API فیلد اختیاری stats.total_coins را اضافه کرده و معنای spent_total_coins را عوض نکرده است. کلاینت جدید total_coins را استفاده می‌کند؛ در اتصال به سرور قدیمی موقتاً عدد خرج‌شدهٔ قبلی نمایش داده می‌شود. موجودی واقعی کیف پول تغییر نمی‌کند.

بیلد :app:assembleWebsiteDebug موفق شد. در زمان این تغییر گوشی 2412DPC0AG با سریال AMLZSW75XOHQRSFU در ADB موجود نبود؛ روی دستگاه دیگر نصب نشده و تست بصری گوشی برای این تغییر انجام نشده است. برای نمایش دیالوگ‌ها و جمع سکه‌های جدید، انتشار APK جدید لازم است؛ نسخه‌های قبلی API موجود را همچنان می‌خوانند.
