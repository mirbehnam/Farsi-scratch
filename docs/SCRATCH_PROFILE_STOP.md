# توقف پروفایل و مأموریت خدای اسکرچ

- مأموریت `lessons_17` از API مأموریت‌ها خوانده می‌شود: ۱۷ درس متفاوت کامل، ۱۸۰۰۰ سکه و همین مقدار XP طبق اقتصاد مشترک فعلی. سرور آماده‌بودن و دریافت یک‌باره را کنترل می‌کند.
- عنوان و توضیحات همه مأموریت‌ها از سرور می‌آیند؛ اپ متن شرط یا جایزه را بازنویسی نمی‌کند.
- فیلد اختیاری `profile_stop` در `/client-controls`: `enabled`, `reason`, `icon`, `message`, `image_hash`, `image_url`.
- آیکون‌ها: `update`, `maintenance`, `notice`, `none`, `custom`؛ متن حداکثر ۱۰۰۰ کاراکتر. عدم وجود فیلد یعنی توقف غیرفعال است.
- فقط بازکردن `LearnerDialog` از عکس پروفایل در هوم و آموزش پیام را نشان می‌دهد؛ هیچ پیام خودکاری در شروع اپ وجود ندارد. فرمان‌های قدیمی محدودیت نسخه همچنان فقط آموزش را مسدود می‌کنند.
- تصویر از origin ثابت API و مسیر `control-images/{hash}` دریافت می‌شود، نه URL دلخواه. اعتبار SHA-256، سقف بایت و ابعاد، دانلود پس‌زمینه و کش محدود با زیرساخت تصاویر آواتار مشترک است. نبود تصویر باعث خطا یا ناپدیدشدن پیام نمی‌شود.
- تنظیمات آخرین پاسخ معتبر کش می‌شوند؛ بررسی دوره‌ای صفحه فعال حدود ۳۰ ثانیه و محدودیت شبکه حداقل ۲۵ ثانیه است. بازکردن پروفایل هم refresh درخواست می‌کند.
- برای آزمون: توقف را روشن کنید، هوم را باز کنید (پیامی نباید ظاهر شود)، عکس پروفایل را بزنید (فقط پیام توقف)، پیام را ببندید؛ هیچ خرید یا زمانی پاک نمی‌شود. حالت بدون آیکون، تصویر خراب/قطع اینترنت، متن بلند و صفحات کوچک لنداسکیپ نیز بررسی شوند.
